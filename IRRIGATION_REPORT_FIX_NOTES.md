# QŪNAR v0.8.1 - Исправление экономического отчёта (13.10.2026)

Заменить в проекте только `app.py`, добавить `core/irrigation_report.py`.
`tests/test_irrigation_report.py` нужен для проверки, на сайт не обязателен.

Изменено:
- В PDF явно показываются исходные параметры экономического расчёта (урожайность пользователя, отдельный прогноз ML, цена, затраты, допущение по урожайности).
- В PDF добавлено сравнение до/после по воде, марже и стресс-марже, включая эффект на всю площадь.
- Если новая технология снижает маржу, первая рекомендация предупреждает об этом вместо заявления экономической выгоды.
- Экономию от изменения полива отделили от двух других независимых сценариев: общего ресурсосбережения и зелёной энергии. Их результаты нельзя суммировать без совместного расчёта.
- Алгоритмы расчёта маржи, нормативов воды, прогноза ML, оптимизатора не менялись.
- Видимая версия остаётся v0.8.1.

Контроль: 3 новых теста прошли; Python синтаксис проверен. Полную визуальную проверку PDF экспорта в этой среде выполнить не удалось из-за отсутствия Streamlit, поэтому итоговый PDF после обновления проекта нужно сверить с интерфейсом.
