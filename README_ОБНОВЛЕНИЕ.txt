QŪNAR v0.8.1 - заключительный патч отчётов и режимов
18.10.2026

ПОЛЬЗОВАТЕЛЮ: в GitHub заменить /app.py и /core/reporting.py.
Папку tests/ загружать необязательно, но желательно для проверки.
Не распаковывайте дополнительную папку проекта в корень GitHub.

Изменения:
1) app.py:
 - дополнительный сценарий до/после теперь не включается автоматически;
 - режим проверки культуры не наследует сценарий смены полива из оценки хозяйства;
 - отдельный сценарий доступен при явном выборе в оценке хозяйства; в животноводстве - только при введённом поголовье;
 - отсутствие поголовья больше не выглядит измеренным нулём и не порождает утверждение, что баланс фермы рассчитан;
 - без маржинальных данных заключение не обещает экономическую выгоду.
2) core/reporting.py:
 - в шести видах экспорта (отдельные и сводные PDF, Word, Excel) теперь вызывается единая нормализация;
 - значения nan/None/null не превращаются в численный ноль и не отображаются как nan;
 - подтверждённый численный ноль сохраняется;
 - подписи и пояснения локализуются по языку отчёта.
3) tests/:
 - проверка сценариев по режимам и отсутствующего поголовья;
 - шесть видов экспорта по трём языкам, в том числе отсутствующие данные и действительный ноль.

Офлайн-тесты: 330 passed (python -m pytest -q tests/ --ignore=tests/test_live_api.py).
Проверка проведена в локальной среде; опубликованный Streamlit ещё не протестирован после обновления.

После обновления GitHub:
 1. Перезапустите приложение, проверьте русский язык и режимы 1,2,5.
 2. Очистите старый «Мой отчёт», чтобы в нём не осталось прежних сформированных разделов.
 3. Повторно сформируйте и скачайте PDF/Word/Excel в русском, казахском, английском вариантах.

Важные научные пределы:
 - расчетные сценарии не являются доказанным фактическим эффектом внедрения;
 - для подтверждения конкретной себестоимости нужны сведения хозяйства;
 - документ D.8 и ML-таблицы для диссертации не пересчитывались этим интерфейсным патчем;
 - файл окончательной редакции диссертации для постраничной правки не был предоставлен в текущем чате.
