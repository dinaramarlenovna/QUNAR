# Загрузка QŪNAR v0.8.1 на действующий Streamlit

Полный архив устроен **без дополнительной верхней папки**: в корне сразу `app.py`, `requirements.txt`, папки `core/`, `data/`, `examples/`, `scripts/` и сопроводительные документы.

1. Сохраните текущий коммит GitHub, чтобы при проблеме можно было вернуть рабочую версию.
2. Распакуйте ZIP на компьютере. **Не загружайте ZIP как файл в репозиторий и не заменяйте один только `app.py`.** Загрузите содержимое архива с сохранением внутренних путей в тот GitHub-репозиторий и ту ветку, к которым привязан работающий сайт Streamlit Community Cloud. Если репозиторий расположен в подпапке, сохраняйте действующую настройку `Main file path`.
3. Streamlit Cloud автоматически пересоберёт приложение по новому коммиту. Не требуется локально запускать Streamlit на ноутбуке. Следите за сообщениями `Manage app → Logs`; старый URL остаётся тем же.
4. Проверьте старт приложения, русский/казахский/английский языки, оптимизацию хозяйства (100 га именно в этом разделе), режим устойчивого компромисса, климатические SSP, отчёты PDF/Word/Excel. Подробные контрольные значения: `QUNAR_СЦЕНАРИИ_ПРОВЕРКИ_УСТОЙЧИВОСТИ_2026-10-17.md` (вместе с пакетом) и `README_SSP_SUSTAINABILITY_SCOPE_2026-10-17.md`.
5. При ошибке сразу скопируйте текст из Streamlit Logs; при критическом сбое вернитесь к сохранённому коммиту GitHub.

Публичный сайт до загрузки этого архива не менялся нами. **Автоматические численные тесты не заменяют браузерный запуск.** NASA POWER в этой среде недоступен из-за DNS, поэтому проверка реального API остаётся отдельной.

Версия интерфейса — `v0.8.1`. Диссертация и исходные RF-данные в этой поставке не правились.
