## A8: единственный актуальный источник чисел

Приоритет: входной JSON → `calculate_case()` → `examples/a8_output/a8_maktaaral_case_results.json` и сгенерированный `a8_maktaaral_for_claude.md`. Для SSP-компромиссов использовать отдельные JSON `a8_canonical_climate_margintolerance_*.json` с явно указанным допуском маржи. Не смешивать эти цели оптимизации.

| Показатель | Обычная исходная структура | Обычная оптимальная | Стресс исходной структуры, недопустима | Стресс оптимальная |
|---|---:|---:|---:|---:|
| Вода, м³ | 725 500 | 750 000 | 725 500 | 600 000 |
| Маржинальный доход, тг | 7 222 217 | 8 130 941 | -2 172 012 | -3 188 623 |
| Частичные выбросы, кг CO₂e | 364 441,9 | 376 780,4 | 364 441,9 | 303 120,8 |

Обычная оптимизация увеличивает маржу примерно на 908 725 тг, одновременно повышая воду и выбросы. Стрессовый допустимый план имеет отрицательную условную маржу. Снижение воды/выбросов относительно недопустимой исходной структуры не доказывает достигнутую экономию. Старые 14,95/16,12 млн тг и 232,14/240,01 т CO₂e из `audit_inputs` устарели после согласования насосной энергии и её затрат; их нельзя переносить в диссертацию.

## Источники и QA

Два старых реестра источников в корне сохранены как рабочие материалы. Их наличие не означает актуальную внешнюю проверку НПА, коэффициентов или редакций. Для закрытия нужны официальная ссылка, дата/редакция, конкретная таблица/строка, единицы, территориальные и временные границы, применённый коэффициент и дата проверки.

Для воспроизведения тестов добавлен `requirements-dev.txt`: `python -m pip install -r requirements-dev.txt`, затем `python -m pytest -q tests/`. Первоначальный запуск в этой среде показал отсутствие pytest; зависимости установлены. Итоговый общий pytest после интеграции: 231 passed, 27.14 s, с установленными региональными данными. Streamlit AppTest прошёл 3 языка × 5 режимов и чистый запуск по сообщению ответственного за интеграцию; это не визуальный браузерный осмотр. Старые `BUILD_*QA*.json` не являются результатом нового запуска. Итог общего прогона фиксировать отдельным отчётом с командой и временем. Офлайн-тесты не закрывают браузер, NASA/WaPOR/SoilGrids и визуальную проверку экспортов.

Для следующей программной работы от пользователя ничего не требуется. Реальные расходы/водомер/дренаж нужны только для доказанного эффекта конкретного хозяйства; актуальный Word нужен для закрытия блока Б.

Повторный `python scripts/build_evidence_bundle.py` выполнен успешно: release JSON/Markdown пересозданы из текущего A8. A3 дополнительно пересчитан командой `python scripts/build_evidence_bundle.py --fetch-nasa --crop Cotton --sowing-date 2025-04-15 --out examples/release_evidence`: статус `scenario_calculated`. Это отдельный пример с реальной базой NASA 1995-2014 в точке Мактаарала и справочным календарём; не полигонный прогноз всех хозяйств и не замена нормативов.
