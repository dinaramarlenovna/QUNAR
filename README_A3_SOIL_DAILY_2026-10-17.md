# QŪNAR v0.8.1: суточный баланс корневой зоны FAO-56 (дополнение к А3)

## Для пользователя: нужно ли что-то скачивать?

**Нет.** FAO-56 — методическое руководство, а не отдельное обязательное приложение. Новый модуль уже включён в полный ZIP QŪNAR. Для реальной проверки онлайн-данных нужен интернет на сервере, запускающем Streamlit. Пользователь не обязан присылать набор почвенных измерений, чтобы провести **иллюстративный** расчёт.

## Что есть в коде

- `core/soil_water_daily.py`: запрос NASA POWER **daily** по выбранному историческому году, проверка полных ежедневных рядов и единиц; расчёт ежедневной ET₀ Penman–Monteith (с G=0, скоростью ветра 2 м, относительной влажностью как приближением фактического парциального давления), условного Kc и ETc; глубина корней, TAW, RAW, Ks; суточный водный баланс, ориентировочное расписание поливов при достижении RAW или проверка варианта без полива.
- `app.py`: раскрывающийся раздел для изучения суточного баланса в режимах Assess My Farm и Check & Select a Crop. Исторические годы 2023/2024/2025, почвы из FAO AquaCrop, возможность ввести собственные θFC/θWP; глубина корней и p из FAO-56 таблицы 22 с редактированием; начальная влажность, дождевой сток, капиллярное поступление, КПД подачи воды. Запуск только по нажатию после подтверждения допущений. Результаты в таблице, графике и summary отчёта.
- `tests/test_soil_water_daily.py`: 15 отдельных проверок, включая закон сохранения воды, влияние полива и осадков, проверку пропусков, единиц NASA, исключение риса, запрет на расчёт без подтверждения.

## Уровень достоверности

1. **FAO / NASA**: подтверждены общие методы и наличие интерфейса daily. Построчная проверка всей официальной документации NASA конкретной даты вызова и настоящая серверная интеграция ещё нужны.
2. **Справочная почва**: выбранный тип почвы — **предположение пользователя**. θFC/θWP из FAO AquaCrop Table 2.13a не являются районированной почвенной картой Туркестанской области. SoilGrids API в настоящий момент приостановлен; внедрять обязательный онлайн вызов SoilGrids нельзя.
3. **FAO-56 Ch. 8**: реализован упрощённый **однослойный** суточный баланс по формулам 82–88. Не моделируются солевой режим, необходимость промывки, слоистый профиль, капиллярная динамика грунтовых вод, деградация качества воды, суточные погоды CMIP6 без статистической детализации и реальные возвратные потоки в речном бассейне.
4. **Полив**: автоматический график по RAW — гипотетическая схема управления, не рекомендации немедленно полить конкретное поле. Уменьшение подачи воды не считается автоматически реальной экономией водных ресурсов региона.
5. **Культуры**: рис не включён в обычный root-zone расчет, для него нужен отдельный баланс затопленного чека. Срок посева допускается только в окне апрель–сентябрь для демо-сезона. Сценарий озимых, посеянных до апреля, требует данных всего цикла, поэтому не маскируется под полный сезон.
6. **Сценарии CMIP6**: в новой вкладке нет прямой подстановки помесячных будущих аномалий в суточную историю, чтобы не подменять проекции синтетической погодой без обоснованного алгоритма downscaling/bias correction.
7. **Оптимизация**: суточные параметры не подставляются автоматически в жёсткий водный лимит для всех культур. Прежний режим сценарной ручной карты по культурам и официальные нормы сохранены отдельно.

## Какие данные от пользователя нужны, а какие нет

**Ничего не требуется для тестового расчёта.** Для проверки применимости к конкретному хозяйству позже желательно узнать точный тип почвы/FC/WP, глубину корней, дату посева, историю фактических поливов, уровень грунтовых вод, качество воды и границы водозабора. Эти данные не нужно придумывать и они не являются препятствием для базовой работы с QŪNAR.

## Релизный чек-лист

- Проверить визуально весь интерактивный блок Streamlit после установки зависимостей.
- Проверить настоящий ответ NASA daily в точке хозяйства, указанные единицы и пропуски.
- Сравнить расчёт на бумаге с FAO-56 Example 38 при одинаковых входах и уточнить динамику Zr.
- Раздельно проверить 2024/2025 и чувствительность к типам почв (особенно супесь vs суглинок).
- Довести до финала отдельную ведомость **всех** НПА и методических источников с актуальной редакцией, реквизитами, таблицами и численными значениями.

Это рабочая интеграционная сборка, публичный Streamlit не обновлён.
