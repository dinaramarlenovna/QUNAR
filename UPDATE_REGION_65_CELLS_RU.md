# Обновление QŪNAR v0.8.1: вся область, 65 ячеек

Распакуйте архив обновления в корень уже восстановленного QŪNAR, где лежит app.py, с заменой совпадающих файлов. Архив содержит только новые и изменённые файлы. Видимая версия остаётся v0.8.1.

## Основные изменения
- Полигонный расчёт поддерживает до 512 ячеек без усечения; вся область занимает 65 пересекающихся номинальных метеоячеек.
- Климатическая норма планирования по полю: 1995-2025; отдельная база сопоставления CCKP: 1995-2014. Исторический районный резерв 2004-2025 подписан отдельно и автоматически не подменяет поле.
- Локальный массив читается из data/nasa_power_region. Полигон пересекается с сеткой, значения усредняются по геодезическим площадям пересечений. Внутри одной исходной ячейки поле получает её ряд.
- Нет усреднения только по успешно скачанным ячейкам: неполный региональный массив вызывает ошибку.
- Месячный набор не блокирует живую суточную загрузку. Если добавлен частичный суточный набор, его пропуски вызывают ошибку. Суточный стандарт UTC проверяется, LST не смешивается с UTC.
- Согласованы текущие A8 JSON и release evidence. Получен реальный пример FAO-56 по NASA для хлопка с явно сценарным календарём; это не измеренный эффект и не замена официальных норм полива.

## Windows-загрузчик без Python
Отдельный QUNAR_NASA_POWER_FULL_REGION_65_CELLS_1995_2025_WINDOWS.zip содержит START_DOWNLOAD.cmd. Распакуйте весь ZIP и запустите этот файл. Итог QUNAR_NASA_POWER_REGION_1995_2025_RESULT.zip можно отправить сюда. Повторный запуск продолжает загрузку. START_DAILY_OPTIONAL.cmd предназначен для более долгой дополнительной суточной загрузки.

## Что не объявлено закрытым
См. AUDIT_CURRENT_RU_2026-10-17.md и SOURCES_VERIFICATION_2026-10-17.md. NASA - сеточные данные, а не микроклимат поля. Точное соответствие номинальных границ всем переменным, локальный Kc/почвы, факторы насоса и электричества, себестоимость, CCKP осадки, независимая сверка Word и измеренный эффект остаются ограничениями.

AppTest проверил запуск пяти режимов в трёх языках. Это не визуальный осмотр браузера/карты и не проверка всех пользовательских комбинаций. Windows PowerShell в текущем окружении отсутствует: скрипт проверен статически, его NASA-запросы и обработка ответов проверены отдельной загрузкой Python.

## Включённые реальные данные
Все 65 рядов NASA уже скачаны и включены в этот архив обновления: 1995-2025, 9 параметров, 217620 месячных значений. DOWNLOAD_COMPLETE.json содержит контрольные суммы. Повторная загрузка на Windows не требуется для использования этой месячной базы. Суточные ряды в пакет не включены.
