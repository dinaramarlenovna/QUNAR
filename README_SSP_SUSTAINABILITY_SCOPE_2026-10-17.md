### Вывод и ограничение

Решение при этих *фиксированных* экономических, водных и углеродных коэффициентах допустимо по математическим ограничениям во всех трёх прогонах. Однако эмпирические климатические оценки трёх культур изменились: для хлопка 100 → 31,82 → 31,82; для кукурузы 100 → 9,09 → 0; для пшеницы 100 → 9,52 → 9,52. Это **сигнал риска экстраполяции**, а не прогноз уменьшения урожайности на соответствующий процент. То, что площадь не изменилась, НЕ доказывает климатическую устойчивость или экономическую эффективность в будущем климате.

Чтобы оценить истинную устойчивость, нужен согласованный помесячный NASA POWER профиль 1995–2014 и пересчёт **ET₀ → ETc → чистая/валовая потребность воды** по культурам под SSP2-4.5 и SSP5-8.5, затем климатически условные оценки урожайности/маржи (или явные стресс-диапазоны) и повторная совместная оптимизация. Живые запросы NASA сейчас не выполнены; без серии нельзя выдавать конкретные м³ экономии от потепления.

Результаты воспроизводятся командой `python scripts/check_ssp_sustainable_a8.py`, JSON результатов сохранён в `examples/release_evidence/QUNAR_SSP_SUSTAINABLE_OFFLINE_RESULTS_2026-10-17.json`. При наличии установленного Streamlit код использует исходный модуль кэширования; вне установленного Streamlit применяется только заглушка декоратора для численных тестов.
