QŪNAR v0.8.1 - исправления переводов, подсказок и выгрузок, 18.10.2026

ИЗМЕНЕНО:
1. app.py: совместим с ранее опубликованным core/ml.py; переведены опции тарифов,
   исследования A8 и названия; уточнены подсказки с (?) для тарифов, насосов,
   показателей воды/энергии, веса критериев и других полей.
2. core/scenario_ui.py: в PDF/Word/Excel поступают локализованные названия
   объединённого сценария. Вместо неподтверждённого 0.70509 кВт·ч/м³
   используется расчёт по фактическому напору и КПД при наличии данных.
   Неизвестное энергопотребление не подставляется как ноль.
3. core/report_localization.py: НОВЫЙ файл, централизованная локализация
   известных внутренних служебных названий и текстов из старых модулей.
4. core/reporting.py: PDF/Word/Excel, включая сводные отчёты, используют
   одинаково локализованные данные. В Excel названия листов переведены.
5. tests/test_localization_integrity_2026_10_18.py: НОВЫЕ тесты (загрузка
   на GitHub не обязательна для запуска сайта).

СЕРЬЁЗНЫЕ ИСПРАВЛЕНИЯ:
- Не рассчитываем расход насосной электроэнергии по 0.70509 без основания.
- Нельзя повторно учитывать насосную услугу поставщика, если выбран тариф
  механизированной подачи воды.
- Отдельный сценарий экономии 20% воды и единый сценарий смены способа полива
  не суммируются и имеют разные исходные условия.
- Название Ember оставлено как имя аналитической организации, но его смысл
  объясняется в подсказке на всех трёх языках.
