QŪNAR v0.8.1. Исправление панели «Мой отчёт», сравнения сценариев и подписей.

ВАЖНО: ЗАГРУЗИТЬ ВСЕ ТРИ ИЗМЕНЁННЫХ ФАЙЛА С СОХРАНЕНИЕМ ПУТЕЙ:
  1. app.py                       -> корень репозитория QUNAR
  2. core/reporting.py            -> папка core/
  3. core/report_variants.py      -> папка core/ (НОВЫЙ файл)
Не загружайте один app.py: он использует новый core.report_variants.

Остальная часть проекта, математические формулы, обученные модели, коэффициенты и публичная версия v0.8.1 не изменены.

ИСПРАВЛЕНО
- «Площадь поля, га» в оптимизации названа «Общая площадь посевов для оптимизации, га».
  Она независима от площади участка, анализируемого в первых режимах.
- Подписаны единицы годового выпуска продукции: т или тыс. шт. (по виду продукции).
- Большинство вещественных полей ввода больше не показывают ненужные .00.
  Для дробного значения используйте точку, например 2.5.
- Порядок всех кнопок отчёта: PDF, Word, Excel.
- Справа фиксированы три независимые навигационные ссылки: ↑ вверху, ▤ к «Моему отчёту» посередине, ↓ внизу.
- «Мой отчёт»: отдельные сохранённые расчёты; галочки на экспорт, удаление каждого, очистка всех.
- Можно сохранить несколько разных расчётов одного режима, повторный идентичный не дублируется.
- В PDF, Word, Excel выгружаются ТОЛЬКО отмеченные варианты. Параметры каждого варианта связаны с его результатами.
- При повторе режима выводится сравнительная таблица отличий, повторные неизменные части сокращаются.
- Для выгрузок отчётов сохранена исходная вычислительная точность: округление чисел в коде научной модели не изменялось.

ОГРАНИЧЕНИЯ
- Сохранение отчётов производится в сессии Streamlit. После перезагрузки браузера, сброса сессии или перезапуска приложения корзина не гарантированно сохранится: скачайте готовый файл заранее.
- Плавающая кнопка «Мой отчёт» перемещает к панели отчётов наверху, которую надо открыть. Это не отдельное всплывающее окно.
- Сравнение сценариев фиксирует изменившиеся исходные данные и результаты, но само по себе не является причинным или статистическим доказательством.
- Онлайн-UI тест в реальном Streamlit Cloud в этой сборочной среде не проводился; проверен исполняемый экспорт и офлайн-регрессия.

ДОПОЛНИТЕЛЬНЫЕ ПРОВЕРКИ
1. Сохранить расчёт «Оценить моё хозяйство».
2. Изменить ОДИН параметр и повторить расчёт; сохранить второй вариант того же режима.
3. Повторно сохранить без изменения параметров: дубликат не должен появиться.
4. В «Мой отчёт» снять галочку с первого варианта и скачать PDF: будет только второй.
5. Поставить галочку обратно, скачать PDF/Word/Excel: появится сравнение двух вариантов.
6. Удалить второй вариант: первый должен остаться в библиотеке.
7. Проверить кнопки ↑ справа вверху, ↓ справа внизу, ▤ к отчёту справа посередине.
