# Воспроизведение А1–А9 и проверка перед публикацией

**Основная версия v0.8.1 не была опубликована этим обновлением.**

0. Для повторного запуска проверок установить зависимости: `python -m pip install -r requirements-dev.txt`. `requirements.txt` содержит зависимости приложения, `requirements-dev.txt` дополнительно устанавливает pytest.
1. Внутри проекта выполнить `python -m pytest -q tests/` и `python scripts/build_evidence_bundle.py`. Скрипт записывает подтверждённые А1/А4/А7/А8. Статус А3 останется `blocked_missing_verified_nasa_baseline`, пока нет исторической погоды.
2. При рабочем интернете на машине с зависимостями выполнить `python scripts/build_evidence_bundle.py --fetch-nasa --crop Corn --sowing-date 2025-04-15` для **условного календаря кукурузы**. Дата посева — демонстрационное допущение, не подтверждённый календарь Мактааральского района. Для иной культуры использовать согласованный срок посадки; рису автоматический Kc не присваивается.
3. Вместо живого подключения NASA можно передать *полный* исходный ответ POWER Monthly API JSON с переменными `T2M,T2M_MAX,T2M_MIN,RH2M,WS2M,PS,ALLSKY_SFC_SW_DWN,PRECTOTCORR` за 1995–2014 и запустить `python scripts/build_evidence_bundle.py --weather-json PATH --crop Corn --sowing-date 2025-04-15`. Программа проверяет комплектность и единицы, но не подделку источника; происхождение JSON нужно подтвердить отдельно.
4. В тестовой копии Streamlit проверить: русский/казахский/английский интерфейс; поиск участка по карте; NASA; FAO-56; ССKP; независимые водные ограничения; нулевые/незаполненные затраты; два способа полива и смешанный; A8; вывод PDF/Word/Excel; отсутствие удвоения воды/электроэнергии. Сравнить каждый итог со сгенерированным JSON.
5. Проверить агрегирование осадков CCKP: самостоятельный CCKP `Anomaly` и разность двух рядов `Climatology` НЕ совпадают. Оба числа сохранены с предупреждением; нужны методические сведения CCKP для объяснения, прежде чем утверждать равнозначность.
6. Перед передачей Claude и защитой пройти отдельный реестр НПА/FAO/IPCC/BNS/NASA/CCKP; проверить конкретные таблицы, номера и редакции, а также категорию хлопка и границы CO₂e.

NASA POWER Monthly API: https://power.larc.nasa.gov/docs/services/api/temporal/monthly/

FAO-56 ETc = Kc × ET₀: https://www.fao.org/4/x0490e/x0490e0a.htm
