# QŪNAR v0.8.1 | уточнение водного баланса при смене полива (14.10.2026)

Переданы **только изменённые файлы**. Сохраняется видимое название версии v0.8.1.

Что заменить в исходном проекте:
- `app.py`: передаёт доступный водный лимит и долю повторного использования воды в сравнительный отчёт; отделяет общую маржу по фактическому вводу от маржи сравнения районных норм орошения; убирает общие советы из специализированных рекомендаций о переходе на другой полив.
- `core/irrigation_report.py`: считает две валовые нормы подачи воды и соответствующий забор свежей воды, проверяет доступный сезонный лимит для каждого варианта; меняет формулировку при невыполнимости исходной и допустимости новой технологии; добавляет локализованные подписи «Основание» / «Ожидаемый эффект».

Для локальных проверок (на Streamlit-сайт не загружать):
- `tests/test_irrigation_water_cap_report.py`: 5 сценарных тестов допустимости.
- `tests/test_irrigation_pdf_export_2006.py`: создание и извлечение текста PDF для сценария 107000 м³.

Проверка: 9 профильных тестов пройдены; синтаксис Python проверен; тестовая генерация PDF выполнена. **Полный браузерный тест опубликованного Streamlit не проводился, потому что пакет streamlit отсутствует в тестовой среде.**

Контрольный пример Сауран, кукуруза, 20 га, 107000 м³ (при доле повторного использования 0%):
- Бороздовой: 6 450 м³/га => 129 000 м³, недостаток 22 000 м³.
- Капельный: 5 160 м³/га => 103 200 м³, резерв 3 800 м³.
- Экономия подачи: 25 800 м³.
- При сценарном эффекте урожайности 0% и дополнительных расходах 15 000 тг/га маржа ниже на ~278 199 тг за сезон. Эта разница не доказывает фактическую прибыль/убыток, а сравнение с превышающим лимит исходным поливом условно.

Не складывать этот результат с обособленными сценариями ресурсосбережения / зелёной энергии. Для корректного сравнения с отчётами 19:53 нужно снова выбрать **Сарыагашский район**, иначе разные нормативы воды и ML-прогнозы несопоставимы.
