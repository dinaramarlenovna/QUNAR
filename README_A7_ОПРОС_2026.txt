ЭМПИРИЧЕСКАЯ БАЗА:
Источник: присланный пользователем файл «Опросник 2026 (Ответы)(3).xlsx», 208 заполненных строк, без пустых ответов.
Q3 водные ресурсы: 120/208 (57,7%). Q7 климатические риски: 93/208 (44,7%).
Это ДВА РАЗНЫХ вопроса с возможностью множественного ответа. Их частоты нельзя считать эмпирически оценёнными предпочтениями 60/40, статистической калибровкой, AHP или Delphi.
Нормирование 93/(120+93) и 120/(120+93) - исключительно исследовательская эвристика для анализа чувствительности. Применяется только при явном выборе пользователем; ранее выбранный «Сбалансированный» 60/40 не меняется.
