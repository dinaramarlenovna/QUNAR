Что изменено:
- Суточные НАСТРОЙКИ FAO-56 (почва, дата посева, длительность фаз, глубина корней и др.) перенесены перед основной кнопкой «Рассчитать».
- Результаты суточного водного баланса и график полива остаются внутри раздела «Результат»; отдельная кнопка запуска суточного баланса больше не требуется.
- Климатические сценарии 2040-2059 доступны в расширенном и исследовательском режимах для модулей «Оценить моё хозяйство» и «Проверить выбранную культуру».
- В месячном FAO-56 добавлена таблица сравнения исторической базы NASA POWER 1995-2014, SSP2-4.5 и SSP5-8.5 на одинаковых входных данных.
- Kc по фазам FAO и эмпирический расчёт эффективных осадков выбраны по умолчанию как СПРАВОЧНЫЕ сценарные предположения, если культура есть в справочнике. Их можно изменить; для точного поля нужны проверенные данные.
- Прогноз RF, исходные таблицы NASA/CCKP, официальные нормы воды и оптимизация НЕ менялись.

Методические ограничения:
- 1995-2014 - сопоставимая климатическая база для CCKP; доступные годы NASA 2015-2025 не удалены, они используются в других расчётах.
- SSP2-4.5/SSP5-8.5 - 2040-2059; температура и осадки меняются помесячно по CCKP.
- Влажность, ветер, радиация, давление сохраняются историческими, поскольку будущие изменения данных параметров пока не включены; это сценарное приближение FAO-56.
- Суточный график полива основан на исторической погоде NASA выбранного года (например, 2025), НЕ является погодным прогнозом 2050 года.
- Для ETc нужны коэффициенты культуры Kc, для оценки водоподачи также метод эффективных осадков и КПД полива. Отсутствие исходных данных не приравнивается к нулю.
