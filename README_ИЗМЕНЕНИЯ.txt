ЧТО ИСПРАВЛЕНО
- Режим «Проверить выбранную культуру»: устранён NameError (economic_energy_kwh)
  при экономическом расчёте. Все модули используют единое определение источника
  электроэнергии; отсутствующие данные остаются неизвестными.
- Проверка смены орошения больше не трактует неизвестную электроэнергию как 0.
- Базовый уровень: источник энергии/выполнения работ обязателен. Ввод района,
  культуры, площади и воды остаётся на месте, а научная диагностика животноводства
  не отвлекает обычного пользователя.
- Исследовательский уровень: расширенная диагностика ML для животноводства,
  а в других режимах сохраняются научные проверки.
- Дополнительный сценарий «до/после» выводит свои НАСТРОЙКИ до кнопки «Рассчитать»,
  а не в блоке «Результат». Для первого появления необходимо выполнить расчёт.
  После первого расчёта изменение параметров пересчитывает результат автоматически.
- Сценарий отдельной фермы не приклеивается к рейтингам культур и оптимизации,
  поэтому больше не дублируется в сводных отчётах по двум другим модулям.
- Животноводство: поголовье всего района не считается поголовьем фермы.
  При отсутствии данных хозяйства ресурсные показатели остаются неизвестными,
  районная статистика показывается отдельно.
- PDF, Word, Excel: значения NaN/None отображаются как «нет данных» (и переводы),
  а длинные дробные результаты округляются при выводе таблиц.
- Отдельные английские служебные фразы в русских/казахских источниках локализованы.
