# Водные потери и А1 — добавление к полной сборке QŪNAR v0.8.1

## Что проверено и что добавлено

**Раньше:** FAO полевая эффективность позволяла вычислять подачу воды на поле. Коэффициенты возвратных потоков, канальная доставка и безвозвратное истощение не рассчитывались.

**Теперь:** модуль `core/water_accounting.py` содержит явный баланс при заданных допущениях:

- чистая потребность растений в воде от полива — `N` [м³/га];
- на поле подано `F=N/eta_field`;
- если подтверждена эффективность доставки `eta_conveyance`, забрано `W=F/eta_conveyance`;
- потери в поле `L_field=F−N`, в транспортировке `L_conveyance=W−F`;
- **восстанавливаемые возвраты** `R=r_field L_field + r_conveyance L_conveyance`;
- **невозвратные потери** `U=(1−r_field)L_field + (1−r_conveyance)L_conveyance`;
- приближённое **водное истощение, связанное с поливом** `D=N+U`; не является исчерпывающим бассейновым водным балансом.

`r_field`, `r_conveyance`, `eta_conveyance` неизвестны по умолчанию: отсутствующие входы дают `None`, а не 0. Не допускается произвольная интерпретация D как реального измеренного водосбережения.

**Существенное ограничение:** пока не учтены суточные изменения запасов воды в корневом слое, стресс K_s, засоление и промывка солей, подпитка грунтовыми водами, состояние инфраструктуры по измеренным фактам, доступность/качество возвратов, границы бассейна и расширение поливных площадей. Отдельно документируем это. Для полноценной привязки к почве требуются: FC, WP, Zr и начальная влажность, почвенная текстура, суточные осадки/ET и полив/дренаж; FAO-56 Ch.8.

Для UI: полный водный баланс доступен в сценарии FAO-56 (режимы оценки культуры, заданные Kc/осадки и технология сравнения) через разворачиваемую панель с параметрами и подтверждением источника.

## А1: сравнение частичного CO₂e по структуре

Новый `core/ghg_structure.py` применяет **введённые пользователем** нормы N кг/га, дизеля л/га и электроэнергии к текущему распределению площадей и оптимальному распределению культур; использует `core/carbon_scenarios.py`, выдаёт сопоставимый частичный CO₂e, только если вводы полные и подтверждены. По умолчанию специфические интенсивности для каждой культуры **не придуманы**. В режиме структуры (`mode4`) отдельная панель после результатов оптимизации принимает данные по каждой культуре. Исходную структуру задают в блоке экономической цели (маржа для этого не нужна).

Ограничение А1: при фиксированных нормах N/дизеля/электричества по каждой культуре эффект обусловлен изменением структуры; не прогнозирует изменение агротехнологии. Нет жизненного цикла, косвенного N₂O, навоза и изменения запасов органического углерода. Достижение сокращения выбросов **не подтверждается** одним сценарным расчётом.
