
# QŪNAR v0.2.1

Исправленная рабочая сборка после проверки v0.2.

## Исправлено
- полностью удалены пользовательские формулировки вида «данные диссертации»;
- источник резервного климата отображается как «Исторический климатический профиль района»;
- старые надписи TURK-RESILIENCE и v0.1.2 удалены;
- блок «Почему система дала такой результат?» заменен полноценным аналитическим выводом;
- анализ сравнивает прогноз с исторической медианой пары «район-культура»;
- анализ интерпретирует климатический профиль, водный баланс, повторное использование воды, энергию и CO₂e;
- WaPOR-показатели включаются в текстовую интерпретацию;
- добавлено предупреждение при слабом пространственном покрытии WaPOR;
- малое число WaPOR-пикселей автоматически снижает показатель надежности;
- добавлен ручной ввод широты/долготы как альтернатива карте;
- карта по-прежнему загружается только по запросу.

## Важно
Автоматическое определение административного района по геометрии поля намеренно еще не включено.
Для научно корректной реализации нужен проверенный слой административных границ Туркестанской области.
До его подключения пользователь выбирает район отдельно, а спутниковые NASA/WaPOR данные берутся по фактической точке/полигону.
