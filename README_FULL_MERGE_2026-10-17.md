# QŪNAR v0.8.1 - единая сборка, 17.10.2026

## Использование
Это полный проект, а не частичный патч. В корне папки `QUNAR_v0_8_1/` находятся `app.py`, `requirements.txt`, `core/`, `data/`, `tests/` и документация. Для обновления сайта заменить файлы проекта этой версией и перезапустить Streamlit. Не добавлять отдельные ZIP-патчи поверх этой сборки.

Вариант команд при локальном запуске:
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```
Тестирование разработчика:
```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q tests/test_reference_fallbacks_2026_10_17.py tests/test_audit_hardening_2026_10_17.py tests/test_core.py tests/test_ghg_structure.py tests/test_economic_feasibility_ui_contract.py tests/test_fao56_irrigation.py tests/test_crossmodule_economic_qa.py tests/test_final_integration_guards.py
```

## Объединённые источники
1. Полная восстановленная сборка с исходным аудитом.
2. Изменения NASA POWER: сетка из 65 точек, период 1995-2025, привязка к 17 территориям.
3. Корректировки логики экономических расчётов и обозначений CO₂e.
4. Новые справочные подстановки для отсутствующих данных и сохранение измеренного нуля.
5. Дополнительные климатические таблицы и контрольные скрипты в `supplementary_climate/`.
6. Word-реестр в `docs/` и полная таблица воды `data/water_fallback_17x_crop_register.csv`.

## Логика отсутствующих значений
- Отсутствие фактического расхода воды: справочная потребность по району, культуре, типу орошения и площади; источник и тип подстановки заносятся в отчёт.
- Отсутствие питьевой воды скота: расчёт FAO по категории, поголовью, температуре; это ТОЛЬКО питьевая вода, не все хозяйственные расходы. Без поголовья объём остаётся неизвестным.
- Неизвестная электроэнергия: фактические кВт·ч неизвестны. Отдельный экономический блок может рассчитать условный сценарий 0,70509 кВт·ч/м³ и ОБЯЗАТЕЛЬНО помечает его как гипотетический; не выдаёт за измерение или официальную норму. При известном напоре и общем КПД используйте функцию `conditional_pumping_energy` для физического насосного расчёта.
- Подтверждённый пользователем измеренный 0 остаётся нулём, без автоматического замещения.
- Производственные затраты/себестоимость без сопоставимой статистики или введённых затрат не трактуются как 0. Цены реализации БНС не подменяют себестоимость.
- Пользовательские отчёты содержат тип и ссылку источника для воды и статус электроэнергии; справочные ресурсы не выдаются за измерение.

## Научные границы
0,70509 кВт·ч/м³, 0,6061 кг CO₂/кВт·ч и региональный водный benchmark 8181,6 м³/га не получили в этом аудите достаточного подтверждения в качестве универсальных официальных норм. Модель хранит их только с оговорками как сценарные величины, пока не получены первичные данные. Исторические и перспективные сценарии НЕ заменяют фактическое сравнение до/после на хозяйстве. В приложении сохраняется v0.8.1.
