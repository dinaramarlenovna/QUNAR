# QŪNAR v0.8.1 — актуальная сборка после аудита NASA, почв и A8

Дата: 17 октября 2026 года. Основной источник расчётов — код и `examples/a8_maktaaral_100ha_inputs.json`; числовые таблицы старых отчётов не имеют приоритета над кодом.

## Что изменено

1. При пользовательском выборе полигона климат NASA POWER для текущего исторического сезона запрашивается по номинальным сеточным ячейкам полигона и усредняется по геодезической доле пересечения. Для следующего сезона по полигону запрашивается **историческая климатическая норма NASA 2004–2025**. Районная точка НЕ используется молча вместо поля; при ошибке NASA пользователь может явно выбрать районный режим.
2. Суточная FAO-56 почвенно-водная модель запрашивает ежедневные данные по полигону с одинаковой сеткой и выравниванием дат.
3. Проверки качества NASA: полная дата/переменная/единицы; допустима не более одной внутренней пропущенной даты на параметр с явной линейной интерполяцией и отметкой об оценочном происхождении. Отсутствие крайних дат или несколько соседних пропусков блокирует агрегацию. Отдельное явно разрешённое восстановление — один отсутствующий внутренний год для данной календарной месячной климатической нормы.
4. При доступном SoilGrids REST API можно получить по пользовательской точке прогнозные характеристики почвы: текстуру (глина/ил/песок), pH, SOC, N, CEC. Только **прогнозные данные**; точное плодородие и свойства всего полигона без грунтовых проб НЕ утверждаются. API SoilGrids временно недоступен в некоторых средах: режим справочного/ручного ввода остаётся.
5. A8 использует единую пару исходных справочных коэффициентов из основного кода: **0,70509 кВт·ч/м³**, **0,6061 кг CO₂e/кВт·ч**. Восстановлены результаты базового и экономического оптимума, устойчивого компромисса, комбинированного стресса и сценарной чувствительности SSP2-4.5/SSP5-8.5. Прежние отчёты с 0,35/0,7 сохранены как исторические (с пометкой «архивная версия»), но их цифры устарели.
6. Добавлена жёсткая опция абсолютного потолка частичных выбросов CO₂e для климатического стресс-сценария, при расчёте маржи и водной нормы на общей границе. Если решение невозможно, оптимизатор возвращает «невыполнимо», а не придумывает распределение культур.

## Что нужно пользователю

Никаких дополнительных файлов данных для локальных расчётов. Для развёрнутого Streamlit распаковать **полный архив** в действующий GitHub-репозиторий, сохранив структуру `app.py`, `core/`, `data/`, `requirements.txt`, и затем открыть карту и провести полигонный запрос. Перед заливкой сохранить текущий коммит (возможность отката). Публичная интеграция NASA и SoilGrids будет проверена по реальным логам сайта.

## Методические границы

- NASA POWER: грубые прогнозно-реаналитические климатические сетки, не измерения микроклимата каждых 10 га.
- SoilGrids: прогнозные почвенные свойства, **не готовая агрономическая оценка плодородия/урожайности**.
- Неизвестные расходы/возвратные потоки воды не превращаются в ноль; переход с бороздового на капельное сам по себе не доказывает снижение безвозвратного водопотребления.
- Режим полного FAO-56 под 2040–2059 на проверенных климатических входах всё ещё требует живой NASA серии и независимой проверки Kc/фенологии.

Полный отдельный список использованных нормативных и научно-методических документов — `РЕЕСТР_ИСТОЧНИКОВ_И_НОРМАТИВНЫХ_АКТОВ_2026-10-17.md`. Реквизиты некоторых коэффициентов ещё требуют подтверждения в первоисточниках; не приписывать им статус действующей нормы без проверки.
