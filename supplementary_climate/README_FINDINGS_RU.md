# QŪNAR v0.8.1 - климатический патч, 17 октября 2026

## Что сделано
1. Верифицирован набор из 65 пространственных образцов NASA POWER, 1995–2025 (372 месяца), 9 показателей: по каждому 24 180 валидных чисел, без пропусков. Прочитаны все исходные 65 JSON.
2. Пересчитаны 17 районных/городских среднемесячных рядов по площадям пересечений номинальной сетки и административных полигонов (EPSG:6933). Созданы прозрачные веса районов. Создан отдельный ряд по области на весах архива.
3. Исключены поля YYYY13: это годовые агрегаты, а не 13-й месяц. Всего исключено 585 рядов показателей, каждый содержит 31 годовое значение (65 × 9).
4. Для PRECTOTCORR выведена сумма осадков за календарный месяц (мм) из среднемесячной величины мм/сутки.
5. Сделано сопоставление наблюдаемых сезонов апрель–сентябрь: климатическая база 1995–2014 против недавнего периода 2021–2025. Регион: +1,0944 °C среднесезонной T2M; сезонная сумма PRECTOTCORR от 87,63 до 58,17 мм (изменение -33,62%). Это описательная оценка gridded NASA POWER, не независимая наземная верификация и не атрибуция изменения климата.

## Методические ограничения, которые нельзя скрывать в диссертации
- Источник содержит **только месячные**, а не суточные данные. Нельзя подсчитать фактическое количество дней T >35, >40, >45 °C; по T2M_MAX таких частот восстановить нельзя.
- NASA POWER выдаёт показатели с разными исходными пространственными разрешениями; геометрия из архива обозначена как **номинальная**, а не подтверждённые нативные границы пикселей. Площадные средние - приближение; выдавать их за точные нативные значения пикселей нельзя. Это касается и практического применения к полигонам полей.
- Файлы JSON не содержат полного списка метаданных единиц исходного запроса. Единицы ALLSKY_SFC_SW_DWN должны подтверждаться метаданными использованного API/исходного запроса перед FAO-56; без этого опасно смешивать MJ/м²/сутки и кВт·ч/м²/сутки (коэффициент 3,6). Преобразование осадков следует также сверить с параметрами исходного запроса.
- Месячная оценка FAO-56 ET0 возможна при подтверждении единиц, поправок на широту, высоту, ветра и радиационных параметров. Точный расчёт ET0 и фактические изменения нормы орошения в этой поставке **не сделаны**. Не нужно заявлять, что проблема уже закрыта.
- Геокодирование и административные границы 17 единиц взяты из присланного архива; независимая проверка их актуальности не выполнена.
- Коэффициент выбросов электроэнергии 0,6061 кг CO₂/кВт·ч, фактическая себестоимость, тесты онлайн NASA/SoilGrids, Tier-1 выбросы, показатели экономического эффекта и валидация кода приложения данным архивом **не проверяются**. Для точечных изменений самого приложения нужен его исходный код; этот патч не заменяет app.py.

## Рекомендуемая формулировка для диссертации
«Для анализа климатических условий сельскохозяйственного производства Туркестанской области использованы среднемесячные данные NASA POWER за 1995–2025 гг. по 65 точкам пространственной выборки. Территориальное усреднение выполнено на основе относительной площади пересечения номинальных расчётных ячеек с 17 административными полигонами. В качестве сравнительной климатической базы выбран период 1995–2014 гг., а в качестве современного пятилетнего интервала - 2021–2025 гг. Полученные показатели характеризуют пространственно агрегированные оценки реанализа и спутниковых продуктов; они не тождественны данным наземных наблюдений и не используются для оценки частоты суточных температурных экстремумов».
