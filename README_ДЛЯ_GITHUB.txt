QUNAR v0.8.1 - согласованные файлы запуска (18.10.2026)

Причина, которую проверяем: app.py и core/ml.py из разных сборок.
Файлы в данном архиве взяты из одной финальной версии.

GitHub не распаковывает загруженный ZIP.
1. Распакуйте ZIP.
2. Замените app.py в КОРНЕ репозитория QUNAR (не в дополнительной QUNAR_v0_8_1/).
3. Замените core/ml.py в папке core В КОРНЕ того же репозитория.
4. Commit changes в той ветке, из которой развёрнут Streamlit Cloud.
5. Reboot приложение Streamlit.
6. Если ошибка повторится, нужен ПОСЛЕДНИЙ текст исключения в Logs, не только строка импорта.

Дополнительно: scripts/verify_deployment_imports.py можно добавить в репозиторий, чтобы
проверять согласованность всех импортов app.py перед публикацией.

Проверка полной локальной сборки: 142 импортируемых имени согласованы.
Этот результат не подтверждает текущее содержимое GitHub: репозиторий отсюда не прочитан.
